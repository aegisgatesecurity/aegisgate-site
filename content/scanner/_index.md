## What Is AegisGate Scanner?

AegisGate Scanner is **antivirus for AI artifacts**. It performs static analysis on files destined for AI/ML pipelines — RAG documents, training datasets, model configurations, agent skills, and code generated by AI tools.

Every file you feed into an LLM is a potential attack vector. A training dataset can contain prompt injection payloads. A RAG document can hide secrets. A model config can expose OT/ICS systems. Scanner catches these risks **before** the artifact reaches your model.

- **Language:** Go 1.26
- **License:** Apache 2.0
- **Dependencies:** Zero runtime dependencies
- **Performance:** 1.88s per MB
- **Patent Pending:** US Provisional App. No. 64/174,824

## Detection Categories

Scanner uses a three-layer detection pipeline: keyword pre-filter → regex pattern matching → ML neural network.

| Category | Patterns | What It Detects |
|----------|----------|----------------|
| 🔐 Secrets | 45 | API keys, cloud credentials, private keys, database connection strings, OAuth tokens |
| 🪪 PII | 42 | SSN, passport, driver's license, credit cards, phone numbers, email addresses, IP addresses |
| 💉 Prompt Injection | 17 | OWASP LLM-01 direct injections, jailbreak attempts, system prompt disclosure |
| 📋 Compliance | 47 | HIPAA, PCI-DSS, GDPR, SOX, NIST, ISO 27001, CIS, FedRAMP, EFPIA, HITRUST |
| 💣 Dangerous Code | 48 | SQL injection, command injection, XSS, path traversal, SSRF, eval/exec, deserialization |
| 🌐 Web Security | 33 | OWASP Top 10, CSRF, open redirects, XXE, prototype pollution |
| 🔌 OT/ICS | 9 | Modbus, DNP3, IEC 61850, ladder logic, HMI exposure, SCADA commands |
| 🤖 AI/ML Security | 18 | Model poisoning, data exfiltration, membership inference, model inversion, adversarial examples |
| 📊 Metadata Rules | 21+247 | Explicit + fallback rules for artifact classification (HuggingFace, PyTorch, ONNX, etc.) |

**Total: 268 regex patterns across 9 categories + CharCNN-BiLSTM ML detection**

| Config files | `.yaml`, `.yml`, `.json`, `.toml`, `.ini`, `.env` | Model configs, environment files |

## Quick Start

### Install

```bash
# Download from GitHub Releases
curl -L https://github.com/aegisgatesecurity/aegisgate-scanner/releases/latest/download/aegisgate-scanner-linux-amd64 -o aegisgate-scanner
chmod +x aegisgate-scanner
```

### Scan a file

```bash
# Scan a single file
./aegisgate-scanner scan document.txt

# Scan a directory recursively
./aegisgate-scanner scan ./training-data/ --recursive

# Output SARIF for CI integration
./aegisgate-scanner scan ./rag-docs/ --format sarif --output results.sarif
```

### GitHub Action

```yaml
- name: AegisGate Scanner
  uses: aegisgatesecurity/aegisgate-scanner@v0.3.0
  with:
    path: ./data/
    format: sarif
    output: scan-results.sarif
```

### Docker

```bash
# ML-enabled (with CharCNN-BiLSTM)
docker run --rm -v $(pwd):/data aegisgatesecurity/scanner:ml scan /data/

# Lite (regex-only, smaller image)
docker run --rm -v $(pwd):/data aegisgatesecurity/scanner:lite scan /data/
```

## Key Features

### Performance
- **1.88s per MB** scan speed
- **O(log n)** keyword pre-filter rejects clean files fast
- **Content-addressed caching** — unchanged files skip re-scanning
- **Concurrent scanning** — multi-core parallel processing

### CI/CD Integration
- **SARIF 2.1.0** output for GitHub Code Scanning
- **8 output formats**: SARIF, JSON, JSONL, CSV, HTML, Text, Binary, Go
- **GitHub Action** for one-step CI integration
- **SBOM generation** (CycloneDX, SPDX)
- **Exit codes** for pipeline gating

### Security
- **Zero runtime dependencies** — no supply chain CVEs
- **Air-gapped capable** — no network calls during scan
- **Archive bomb protection** — size limits on extracted files
- **Baseline suppression** — silence known/accepted findings

### ML Detection
- **CharCNN-BiLSTM v13** — 1.6M parameters
- **< 1ms inference** on CPU
- **No GPU required** — runs on any machine
- **Heuristic fallback** — works without model file
